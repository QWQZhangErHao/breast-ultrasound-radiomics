# 统计测试与对比实验(以现版代码为基准,2026-09-04)

配置与数据同 `现版canonical_结果摘要_2026-09.md`。所有 ΔAUC 均为**同一 70/30 划分下逐种子配对**(n=10),t-test + Wilcoxon + 5000 次 bootstrap 95%CI。
多重比较:主分析 Bonferroni **α=0.005**(10 个预设模型级比较:5 分类器×2 尺度)。

## A. 尺度对比(0–4 mm,10 种子)
XGB:0.787→**1mm 0.808**→0.792(2)→0.794(3)→0.787(4)。
| 比较 | 模型显著(p<.05) | 方向 |
|---|---|---|
| 0→1mm | RF Δ+0.010(p=.035)、XGB Δ+0.020(p=.046) | 仅 RF/XGB 小幅升,均**未过 α=.005** |
| 1→2mm | RF Δ−0.009(p=.006) | XGB 亦降(.808→.792,p=.17);1mm 相对更高但不显著 |
| SVM/LR | 0→1mm 略降(Δ −0.011/−0.008) | 线性分类器对瘤周扩增无益 |

→ 结论措辞:**“1 mm 使树模型(XGB/RF)点估计最高,但相邻尺度差在 10 种子下仅名义显著、未过 Bonferroni;线性模型无获益”**——宜写为“参考尺度的选取基于点估计与一致趋势”,非“显著最优”。

## B. 融合/Doppler 有无(全部 5 模型)
| 比较 | 关键结果 | 校正后 α=.005 |
|---|---|---|
| base→+VFA | 全模型 p≥.10,Δ≈0 | 无 |
| base→+3 | SVM +0.016(p<.001)、LR +0.023(p=.0002)、RF +0.023(p=.0003)、XGB +0.020(p=.016)、KNN +0.011(p=.12) | **SVM/LR/RF 存活**;XGB 名义(p=.016)未过;KNN 无 |
| +VFA→+3 | 同上,加 VFA 后再加 Energy+GLNU 增益主要来自后二者 | SVM/LR/RF 存活 |
| +3→+13 / +13→+21 / +3→+21 | 全模型 Δ≤0.011、全 p≥.08 | 无显著 |
| XGB +13→+21 | Δ+0.004(p=.13) | 无 |

→ 写作要点(与论文原叙事不同,重要):
- **+3 的增益对 SVM/LR/RF 在校正后仍稳健**;XGB(预设主模型)反而只是名义显著(p=.016<.05 但>0.005);
- 从 3→13→21 扩特征**无统计显著提升**(Δ≤.004,邻近 p≥.09)——支持“3 特征已足够”;
- 建议正文不再写“XGB 最优/tree 远超 linear”;现版显示**线性与 RF 的 Doppler 增益更稳**,XGB 边缘。
