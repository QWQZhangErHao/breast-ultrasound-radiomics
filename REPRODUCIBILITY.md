# Reproducibility Guide · 复现指南

This repository ships the **de-identified imaging-feature matrices** (no raw
ultrasound images) plus the code needed to reproduce the paper's **core
radiomics numbers and figures** end to end.

本仓库内置**去标识化影像组学特征矩阵**（不含原始超声图像），并给出可端到端复现论文核心放射组学数字与图件的代码。

---

## 1. What is included · 内容

| Path | Content |
|------|---------|
| `data/features/` | Peritumoral BUS radiomic features, 0–4 mm (`benign_/malignant_{0..4}mm.csv`; 335 benign + 211 malignant = 546 lesions) |
| `data/flow/` | Doppler: `blood_flow_features_{benign,malignant}.csv`, `{benign,malignant}_flow_density.csv` |
| `reproduce/run_radiomics_roc_5models.py` | Reproduces the **1-mm grayscale + 3 Doppler** 10-seed nested-CV ROC for SVM / LR / RF / XGBoost / KNN |
| `results/` | Pre-computed outputs: `canonical_scale6.csv` (0–4 mm metrics), `roc_1mm_plus3_5models.pkl` (ROC arrays), `roc_1mm_plus3_xgb.npz` |
| `figures/` | Paper figures: peritumoral scale comparison (0–4 mm) and 1-mm multimodal ROC |
| `validate_pipeline.py`, `compute_doppler_ablation.py`, `run_1mm_pipeline_optimized.py`, … | Original mother pipeline used to derive the manuscript numbers |

> **Note on data:** only de-identified, image-derived **feature tables** are
> committed (pseudo `patient_name`/`image_id`, benign/malignant label, no
> image content, no clinical demographics). Raw ultrasound (grayscale /
> Doppler) images remain private per the ethics/data-governance agreement.
> The public **BUSI** grayscale benchmark for external validation is
> available at https://scholar.cu.edu.eg/?q=afahmy/pages/dataset; scripts
> (`validate_busi_standard.py`, `current_code_results/dl_supp/`) assume you
> place it locally.

## 2. Environment · 环境

```bash
# conda
conda env create -f environment.yml
conda activate breast-radiomics

# or pip (Python 3.9+)
pip install -r requirements.txt
```

We recommend `scikit-learn==1.2.2` + `xgboost>=1.7` to match the reported
numbers byte-for-byte.

---

## 3. Reproduce the core radiomics results · 复现核心放射组学结果

```bash
# 10-seed nested-CV ROC for the five classifiers on 1 mm grayscale + 3 Doppler
python reproduce/run_radiomics_roc_5models.py
```

Expected (matches manuscript, Table 1 "+3 Doppler (optimized)" row and Figure):

```
SVM       0.804 +/- 0.042
LR        0.812 +/- 0.045
RF        0.821 +/- 0.028
XGBoost   0.827 +/- 0.028
KNN       0.735 +/- 0.024
```

The script writes `results/roc_1mm_plus3_5models.pkl`, which drives the
multimodal ROC figure.

```bash
# quick smoke test (2 seeds)
python reproduce/run_radiomics_roc_5models.py --seeds 2
```

## 4. Other results in the paper · 论文中的其它结果

- **Peritumoral scale sweep (0–4 mm)** → pre-computed in
  `results/canonical_scale6.csv` (used by the scale figure).
- **Doppler ablation Table 1** → regenerated by the mother script
  `compute_doppler_ablation.py` (requires the same `data/` layout; prints the
  AUC table and saves `doppler_ablation_results.pkl`).
- **Deep-learning grayscale baseline & BUSI external validation** → code under
  `current_code_results/dl_supp/` and `validate_busi_standard.py`; model
  weights are not committed, and BUSI images must be downloaded separately.
